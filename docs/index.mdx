# EHRCMS documentation

EHRCMS is a prototype for managing business premises, inspections, compliance findings, applications, and certificates in environmental health work.

The **Internal library** contains the product requirements, role journeys, screen specifications, design briefs, and implementation plans. Team members will need to sign in once the site is deployed with authentication enabled.

The current application is a frontend prototype. Its authentication, payments, uploads, assessments, and regulatory decisions are simulated; it does not issue official documents.

For local setup and the current demo journey, see the project README in the repository.
